# Saigely Product Brief

## Purpose

This brief defines the product represented by the current repository.

# Product Thesis

A focused AI chat product can demonstrate a meaningful full-stack system when authentication, streaming, configuration, persistence, and operational boundaries are treated as first-class features.

# Core Loop

Authenticate → configure → compose → stream → persist → revisit.

# Product Surfaces

## Login

Better Auth provides the entry point and GitHub/Google OAuth integrations.

## Chat workspace

The protected chat route combines the sidebar, message list, composer, Markdown rendering, settings, connection state, and user menu.

## Settings

Users edit theme, model, agent, temperature, reasoning, and verbosity preferences.

## Conversation history

Users see summaries, open a conversation, create a new conversation through a first message, and delete conversations.

# Out of Scope for the MVP

Resume or job workflows, multi-user workspaces, billing, prompt libraries, agent authoring, arbitrary binary uploads, and cross-provider tool execution are not implemented.
