# Saigely Vision

## Product Vision

Saigely is a calm, capable AI workspace: sign in once, configure the assistant to fit the task, and keep a durable history of conversations.

# Product Promise

Saigely should make a normal AI chat feel dependable: fast feedback through streaming, useful Markdown output, recoverable history, and understandable settings.

# Target User

The primary user is a technically curious individual who wants a personal AI chat application with more control and a clearer architecture than a disposable demo.

# Core Experience

1. Authenticate with GitHub or Google.
2. Open the chat workspace.
3. Choose model, agent, reasoning, verbosity, temperature, and theme.
4. Send a prompt, optionally including text-file attachments.
5. Watch the response stream and return to the conversation later.

# Experience Principles

## Streaming should feel continuous

The UI shows chunks as they arrive and handles completion, error, token refresh, and reconnect states explicitly.

## Users stay in control

Preferences are visible and editable. The application does not hide model behavior behind an opaque workflow.

## History should be useful

Conversation summaries are ordered by activity and preview the opening user message.

## The MVP should be honest

Saigely does not currently include files as a separate library, billing, teams, tool calling, or broad workflow automation.
