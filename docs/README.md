# Saigely Documentation

This directory is the source-of-truth documentation for the Saigely MVP. It follows the numbered structure used by AspAIre so project intent, architecture, product domains, development practice, and reference material remain easy to find.

## Suite map

| Area | Purpose |
| --- | --- |
| [00-Project](00-Project/) | Vision, product brief, MVP scope, foundations, decisions, and roadmap |
| [01-Architecture](01-Architecture/) | Runtime boundaries, authentication, data, frontend, GraphQL, deployment, and gateway |
| [02-Domains](02-Domains/) | Product behavior and ownership for the implemented domains |
| [03-Development](03-Development/) | Coding, component, contribution, and testing guidance |
| [04-Reference](04-Reference/) | Environment, schema, service, and database references |
| [operations.md](operations.md) | Production runbook for Vercel, Fly.io, Neon, MongoDB, and OpenAI |

## Documentation status

Saigely is a complete portfolio MVP, not a production SaaS platform. These documents describe the current code and deployment shape first. Future ideas are marked as future work and should not be read as implemented capability.
